# Capri Island Slot

Spielbares Capri-Island-Spiel (Spielgeld) — Web sofort im Browser, Swift für Xcode.

## Sofort spielen (Web)

```bash
open CapriIsland/index.html
```

Oder Datei `index.html` im Browser öffnen. Kein Build nötig.

## Xcode (iOS)

1. Neues iOS-App-Projekt **Capri Island** (SwiftUI, iOS 17+).
2. Inhalt von `ContentView.swift` in die Xcode-`ContentView` einfügen.
3. `Capri_IslandApp.swift` muss `ContentView()` starten.
4. Gelbe XIB-Dateien löschen — nur Swift (blaues S).
5. ▶ Run.

## Dateien

| Datei | Zweck |
|-------|--------|
| `index.html` / `game.css` / `game.js` | Web-Spiel |
| `ContentView.swift` | SwiftUI-Spiel |
| `Capri_IslandApp.swift` | iOS `@main` Einstieg |

Kein echtes Geld — nur Unterhaltung mit virtuellem Guthaben.
