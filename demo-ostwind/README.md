# Ostwind — Demo-Thema

Eigenständige Landingpage für eine **Segelschule an der Ostsee**.

Nicht verwandt mit Taxi-App oder Collection-Shop — nur ein frisches Marken-/Design-Thema.

## Öffnen

```bash
open demo-ostwind/index.html
```

oder lokal mit einem einfachen Server:

```bash
cd demo-ostwind && python3 -m http.server 5173
```

Dann: http://127.0.0.1:5173
